# One More Default

Ein Designlabor für die Frage: Wie viel muss ein Button-Spec-Sheet festlegen, damit ein Agent im nächsten Screen denselben Button verwendet?

## Erster Versuch

Öffne [Button-Spec-Sheet](experiments/button.html) nach dem Klonen direkt im Browser. Die Matrix dient als feste Vergleichsvorlage. Die ausführbaren Aufträge für die drei Versuche stehen in [Experiment 01](experiments/README.md).

## Mit Paper auf dem Mac arbeiten

1. [Paper Desktop](https://paper.design/) öffnen, eine neue Datei namens **One More Default** anlegen und geöffnet lassen.
2. In Paper oben rechts **Connect your agent** öffnen und **Codex** auswählen. Die lokale Verbindung nach den angezeigten Schritten einrichten. [Offizielle MCP-Anleitung](https://paper.design/docs/mcp)
3. Codex im geklonten Repository starten. Zum Verbindungstest fragen: „Wie heißt die geöffnete Paper-Datei? Liste ihre Seiten auf.“ Danach Versuch 1 starten.
